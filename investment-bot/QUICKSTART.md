# クイックスタートガイド（bitFlyer + 仮想通貨）

5分で投資ボットを動かしてみよう！

## ステップ1: 環境構築（2分）

```bash
cd investment-bot
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## ステップ2: 最小限の設定（1分）

`.env` ファイルを作成（APIキーは空でOK）:

```bash
cp .env.example .env
```

## ステップ3: テスト実行（2分）

ドライランモードで動作確認:

```bash
python main.py --dry-run
```


## 次のステップ

### 1. bitFlyer APIキーを設定（本番運用には必須）

#### bitFlyer API取得
1. bitFlyerにログイン
2. 設定 → API
3. API利用申請
4. APIキーとAPI Secretを取得
5. `.env` に設定

### 2. Twitter APIを設定（任意）

#### Twitter API取得
1. X Developer Portalにアクセス
2. アプリを作成
3. APIキーを取得
4. `.env` に設定

### 3. Discord Webhookを設定（推奨）

#### Discord Webhook設定
1. Discordサーバーの設定
2. 連携サービス → Webhook
3. 新しいWebhookを作成
4. URLを `.env` に設定

### 4. OpenClaw Cronで定期実行

1時間ごとに自動実行:

```bash
openclaw cron add --job '{
  "name": "investment-bot-hourly",
  "schedule": {
    "kind": "every",
    "everyMs": 3600000
  },
  "payload": {
    "kind": "agentTurn",
    "message": "cd /Users/yudai/.openclaw/workspace/investment-bot && python main.py --dry-run --notify",
    "model": "zai/glm-4.7"
  },
  "sessionTarget": "main"
}'
```

### 5. 本番運用（慎重に！）

必ず以下の手順で：

1. **1週間ドライラン**: パフォーマンスを監視
2. **小額からスタート**: 1万円〜5万円
3. **少しずつ増額**: 実績を見て判断

本番モード:
```bash
python main.py --live --notify
```

## よくある質問

### Q: APIキーがなくても動かせる？

A: はい！ニュースとチャートデータの分析は動きます。TwitterとbitFlyerの機能だけ無効化されます。

### Q: ドライランとは？

A: 実際には注文せず、シミュレーションのみ行うモードです。動作確認に最適です。

### Q: いつでも本番運用できる？

A: おすすめしません。最低1週間はドライランでパフォーマンスを確認してください。

### Q: 損失が出たらどうする？

A: 即座に運用停止してください。コードを見直して、原因を特定してから再開してください。

### Q: 1万円で本当に年利20%達成できる？

A: 可能ですが、手数料と市場のボラティリティを考慮する必要があります。小額から始めて、実績を見て判断してください。
