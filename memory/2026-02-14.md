# 2026-02-14

## 投資ボットプロジェクト開始

ユーザーの要望に基づき、年利20%を目標とする自動取引システムを設計・実装。

### 目標
- 年利20%以上達成（最低目標）
- 1時間ごとの情報分析（ニュース、SNS、チャート）
- 勝率55%以上で取引実行
- bitFlyer APIを使用

### システム構成

#### モジュール
1. **collector.py**: 情報収集（ニュース、Twitter、チャート）
2. **analyzer.py**: 感情分析、テクニカル分析、シグナル生成
3. **predictor.py**: 勝率予測（機械学習）、過去データからの学習
4. **trader.py**: 取引実行（bitFlyer API）、リスク管理
5. **monitor.py**: 監視、Discord通知

#### 取引戦略（仮想通貨版）
- 対象通貨: BTC_JPY, ETH_JPY, XRP_JPY, BCH_JPY, LTC_JPY
- 勝率閾値: 55%
- リスクリワード比: 2:1
- 利益目標: +2.5%
- 損切り: -1.2%
- 1通貨最大ポジション: 残高の40%
- 日次最大損失: 残高の5%
- 日次最大取引数: 20回

#### 技術スタック
- Python
- yfinance: チャートデータ
- scikit-learn: 機械学習
- pandas/numpy: データ処理
- SQLite: データベース
- bitFlyer API: 取引実行
- Twitter API: SNS収集

### 年利20%達成のための戦略

1. **高頻度取引**: 1日20回の取引で機会を増やす
2. **ボラティリティ活用**: 仮想通貨の高いボラティリティを活用
3. **損切り徹底**: -1.2%で損切り、大きな損失を回避
4. **利益目標控えめ**: +2.5%の利益目標、頻繁に利益確定
5. **分散投資**: 5通貨に分散、1通貨の暴落の影響を最小化
6. **機械学習活用**: 勝率55%以上でのみ取引、低い勝率をスキップ

### 次のステップ
1. ユーザーに報告
2. bitFlyer APIの申請を依頼
3. Twitter APIの設定を依頼（任意）
4. テスト実行
5. OpenClaw Cronで定期実行設定

### 注意点
- 最初はドライランモードで動作確認
- 小額からスタート（1万円〜5万円）
- 損失拡大時は即座に運用停止
- 投資は自己責任
